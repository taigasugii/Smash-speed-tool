# ショットごとのフットワークと、ショットの出来の目安

`smash_speed/footwork.py`（ROADMAP D4）。ショットの一覧（`shots.csv`）と選手の位置（`players.csv`）から、
ショットごとに「打った選手が、相手に打たれてから自分が打つまで・打った後にどう動いたか」と、
決まった物差しで出した「ショットの出来の目安」（0〜100 点）を出す。

## 使い方

- ショットの一覧と一緒に：`smash-speed shots ... --footwork`（`python -m smash_speed.shot_list ... --footwork`）。
  選手の位置（`--players`）も出す。GUI では「ショットの一覧」の「選手の動き（構え・動き出し・戻り）と、ショットの出来の目安も出す」。
- 出した一覧から書き直す：`python -m smash_speed.footwork <ショットの一覧の出力先>`（`shot_list.json` のキャリブレーションを使う）。
- 合成データで確かめる：`python -m smash_speed.footwork --bench`。

出力：

- `footwork.csv`：1 ショット 1 行（`shot_index` は `shots.csv` の何行目か）。
- `footwork.json`：選手ごと（`h0`・`o0`）とラリーごとのまとめ。数字は「確かでない」行を除いて出す。
- `shot_list.json` の `footwork`：選手ごとの短いまとめ。

## 1 行の中身

1 行は「そのショットを打った選手」の動き。「受けた球」は同じラリーの相手の 1 本前のショット（サーブには無い）。

| 列 | 意味 | 出し方 |
|---|---|---|
| `split_step`・`split_dt_s`・`split_height_m` | 相手が打つ時の小さなジャンプ（スプリットステップ）、その時刻（相手が打った時刻との差。負なら前）、高さ | 相手が打つ 0.45 秒前〜0.2 秒後に、足が 4〜25 cm 浮いたコマがあるか。下の「浮いた高さ」 |
| `reaction_s` | 相手が打ってから、打つ所へ向かって動き出すまで [s] | 打つ所（打った時の足元）へ向かう向きに 1 m/s より速く 0.1 秒続けて動き出した時刻。負なら相手が打つ前に動き出した（読んでいた）。相手が打つ 0.2 秒前からもう動いていたら、前の動きの続きなので空欄 |
| `move_distance_m`・`move_peak_mps` | 受けた球を打たれてから打つまでの移動距離と最高の速さ | `movement` と同じならし方（0.2 秒・最高の速さは 0.12 秒） |
| `prep_s` | 打つ所（打った時の足元）から 40 cm 以内に着いてから打つまで [s] | |
| `base_x_m`・`base_y_m`・`recovery_m`・`recovery_s` | そのラリーでいちばんいた所（ラリーの間の足元の中央値）、打った時の足元からの距離、そこから 60 cm 以内へ戻るまでの時間 | 次に相手が打つまで（なければ 1.5 秒）に戻らなければ空欄 |
| `jump`・`jump_height_m` | 跳んで打ったか、その高さ | 打つ 0.35 秒前〜0.15 秒後に 10 cm より浮いたか、`players.ground_jumps` が跳んでいるとしたコマがあるか |
| `uncertain`・`uncertain_reason` | 確かでない行とその理由 | 窓の中で、体が画面の端で切れている（枠が画面の端から 3 px 以内）、位置が出ていないコマ・補ったコマが 3 割より多い、カメラがない |
| `quality`・`q_*` | 出来の目安と、その項目ごとの点 | 下の「出来の目安」 |

### 浮いた高さ

人の検出の枠の下の辺（足）と上の辺（頭）が、そのコマの前後（0.15〜0.45 秒離れた所。ジャンプは 0.3〜0.75 秒）の中央値を
直線でつないだ基準より何 px 上がったかを、その位置の 1 m の縦の長さ [px]（キャリブレーションのカメラで出す）で割る。

- 跳ぶと足も頭も同じだけ上がる。足と頭の**小さい方**を使うので、足だけ（踏み込み・足を上げる）や頭だけ（伸び上がる）の動きは数えない。
- カメラへ近づく・離れる動きも枠を上下させる。そのときは枠の高さが変わるので、枠の高さが基準から 3% より変わったコマは浮いたとみなさない
  （跳んでも枠の高さはほぼ変わらない）。ジャンプでは、いちばん高いコマの枠の高さが変わっていたら高さを出さない（空欄）。
- 相手が打った時に 2.5 m/s より速く動いていたら、スプリットステップは決めない（空欄）。走りながらの浮き沈みと分けられないため。

## 出来の目安（`quality`）

**学習したものではなく、決まった物差し**。種類ごとに使う項目だけを 0〜1 点にし（2 つの値の間を直線で。外は 0 か 1）、
出た項目の平均 × 100。項目が 2 つより少なければ出さない。物差しの値は一般的な目安で、選手のレベル・練習の目的で変わる
（`footwork.QUALITY_TERMS` で変えられる）。

| 項目 | 使う種類と物差し（0 点 → 1 点） | なぜ |
|---|---|---|
| 打った高さ `q_height` | スマッシュ 2.0 → 2.8 m、クリア・ドロップ 1.9 → 2.7 m、ドライブ・プッシュ 0.8 → 1.5 m、ネット 0.6 → 1.4 m | 上から打つ球は高い打点ほど角度と時間の余裕がある。低い球はネットより下がる前に打つほど攻められる |
| 速さ `q_speed` | スマッシュ 150 → 300 km/h、ドライブ 80 → 160、プッシュ 50 → 110 | 速さで押す種類だけ。クリア・ドロップ・ネットは速さが良さではないので使わない |
| 落ちた所の深さ `q_depth` | クリア・ロブ：ネットから 4.0 → 6.2 m（深いほど良い）、ドロップ 3.0 → 1.5 m、ネット 2.5 → 0.8 m（浅いほど良い） | 奥へ運ぶ球は相手を後ろへ下げ、前へ落とす球は相手を前へ出す。相手の側に落ちなかった球には出さない |
| 打つ前の余裕 `q_prep` | どの種類も 0 → 0.4 秒 | 打つ所に早く着いて構えられたか（フットワークの結果）。確かでない行では使わない |

サーブ・ロブは高さを、種類が分からない球は全部の項目を使わないので、点が出ないことが多い。

## 合成データでの確かめ（`--bench`）

`synth_rally_players` の合成ラリー（3 セッション × 5 ラリー、30 fps）に、`session_hops` で相手が打つたびのスプリットステップ
（75%、高さ 5〜12 cm、0.2〜0.26 秒）とスマッシュのジャンプ（70%、25〜45 cm、0.5 秒）を入れ（`observe_players` の `lift`）、
いつもの揺れを足して写したもの。正解のショット（打った時刻・打点・着地点は正解）で測り、正解の足元を同じ手順で測った値と比べる。

| | 横の遠いカメラ（`rally_camera`） | 角の低いカメラ（`corner_rally_camera`） |
|---|---|---|
| 確かでない行 | 3% | 3% |
| スプリットステップ 再現率・適合率 | 0.97・0.97（決めた 32 本） | 0.90・1.00（29 本） |
| その時刻のずれ（中央値・90%） | 0.02・0.03 秒 | 0.03・0.03 秒 |
| 動き出しまでのずれ（中央値・90%） | 0.07・0.13 秒（平均 0.07 秒早く出る。44 本） | 0.03・0.10 秒（平均 0.06 秒早く出る。46 本） |
| 打つ前の余裕のずれ | 0.03・0.09 秒 | 0.03・0.07 秒 |
| 戻るまでのずれ | 0.03・0.13 秒 | 0.03・0.13 秒 |
| 移動距離のずれ | 0.27・0.54 m（平均 0.22 m 短く出る。ならすため） | 0.25・0.55 m（0.16 m 短い） |
| ジャンプ | 高さが出たのは跳んだ 9 本中 3 本（3 本とも合う、高さのずれ 6 cm） | 9 本中 1 本（合う、ずれ 4 cm） |

- 合成の選手は、打つ所へ着くのがちょうど打つ時刻（走りながら打つ）なので、ジャンプのほとんどは「カメラへ近づきながら跳んだ」形になり、
  枠の高さが変わって高さを出さない（空欄）。実際のジャンプスマッシュは止まってから跳ぶことが多い。
- 合成の選手は相手が打つ時にも速く走っていることが多く、そのスプリットステップは決めない（空欄）。

## 実動画で見たこと（IMG_5109、40 秒、角の低い所から 1 台）

夜のエージェントが出したショットの一覧（`--players`）から書き直して、2 か所はコマも見た。

- 手前の選手は足が画面の下の端で切れているコマが 46% あり、18 本中 17 本が「確かでない（体が画面の端で切れている）」になった。正しい。
- 奥の選手は 16 本中 15 本が確か。スプリットステップは 11 本で 0 本。14.3 秒・25.9 秒の前後のコマを見ると、構えて立っていて
  小さく跳んでいるようには見えず、合っていそう（基礎打ちで、打ったらその場で次を待つ形）。14.3 秒の窓のはじめの浮き（11 cm）は
  13.8 秒の自分のスマッシュのジャンプの着地。
- 奥の選手のスマッシュ 4 本のうち 2 本が「跳んだ」（14〜17 cm）。13.8 秒はコマでも跳んでいた（はじめの閾値 15 cm では落ちていたので
  10 cm にした）。
- 奥の選手の最高の速さ 7.8 m/s（27.4 秒）は速すぎる。足元の位置の飛び（追跡の外れ・ジャンプの補い漏れ）が残っていそう。
- 動き出しまでは、奥の選手で中央値 0.16 秒。相手が打つ前から動いていた（空欄にした）球が多い。

## 足りないこと

- 正しいスプリットステップ・動き出しの時刻の実動画の正解はない（コマで 2 か所見ただけ）。
- 人の枠だけを使うので、体の向き・踏み込みの足・ラケットの準備は見ていない（E のフォームの課題）。
- ダブルスは、1 側 2 人のときに打った時の足元に近い方を打った人にするだけで、確かめていない。
