# 速さを重ねた動画と見どころの動画

ショットの一覧（`smash-speed shots`・GUI の「ショットの一覧」）の結果を元の動画に重ねて書き出す（`smash_speed/overlay.py`）。

## 何が描かれるか

- **シャトルの通り道**（黄色）：見つけたシャトルの最近 0.4 秒の点。新しい点ほど大きい。
- **当てはめた軌道**（種類ごとの色）：いまのショットの、打った所から着地か次の打球までの計算した飛び方。打ってから今までの部分は太い。
- **種類と初速**：打った所の近くに「スマッシュ 312 km/h」のように 1.5 秒出す（初速が出なかったショットは種類だけ）。
- 見どころの動画では、左上に「速いスマッシュ 1 位：312 km/h」「長いラリー 1 位：12 本」も出す。

描くのは `shots.csv`（打った時刻・打点・初速度・終端速度）と `detections.csv`（シャトルの検出）で、解析し直すわけではない。
軌道・打点が正しくないショット（種類が「不明」・初速が出ていないなど）は、その分だけ描かれない。

## 使い方

GUI：「ショットの一覧」の「動画に書き出す」の所で、

- 「重ねた動画を書き出す」：解析した区間すべてか、決めた区間を `<一覧の出力先>/overlay.mp4` に書く。
- 「見どころの動画を作る」：速いスマッシュ（か種類を問わないショット）の上位 N 本と、長いラリーの上位 N 本を
  `<一覧の出力先>/highlights/` に 1 本ずつ書き、つないだ `highlights.mp4` と一覧の `highlights.json` も書く。
  1 本は打つ 1 秒前から 2 秒後まで（ラリーは最初の打球の 1 秒前から、最大 60 秒）。スマッシュが 1 本もなければ種類を問わずに選ぶ。

進み具合は画面の下に出る。終わると「できた動画を開く」「見どころを開く」「フォルダを開く」が出る。

コマンド：

```
smash-speed overlay <一覧の出力先> [--out 動画.mp4] [--start 14 --end 30] [--height 720]
                    [--no-trail] [--no-trajectory] [--no-labels] [--no-audio] [--opencv]
smash-speed overlay <一覧の出力先> --highlights [--top 5] [--type smash|all|clear…] [--rallies 2]
                    [--before 1.0] [--after 2.0] [--out フォルダ]
```

`python -m smash_speed.overlay …` も同じ。

## 基礎打ちの見どころ（コート合わせなし、ROADMAP v2 の K2）

基礎打ちの解析（`python -m smash_speed.drill`、GUI のホームの「基礎打ちを解析する」）の出力先を渡すと、コート合わせがなくても
**長く続いた打ち合いの上位 N 本** を見どころとして書き出す（`overlay.write_drill_highlights`）。

```powershell
smash-speed overlay outputs\drills\IMG_5287 --highlights --streaks 3
```

- 描くもの：シャトルの通り道（検出の点、黄色）・打った所の印（打球の時刻にいちばん近いシャトルの点に広がる赤い輪）・左上に順位と本数・
  右上にその打ち合いの今までの本数（「27 本」）。当てはめた軌道・種類・初速はコート合わせがないので描かない。
- 続いた打ち合いは、G4 の区切り（`drill_segments.csv`）があればそれを、なければ打球の間が 2.5 秒より空いた所で区切る（`drill_streaks`）。
- 1 本は打ち合いの始まりの 1 秒前から終わりの 2 秒後まで（長いものは 60 秒まで）。出力は `<出力先>/highlights/`（1 本ずつと、つないだ
  `highlights.mp4`・`highlights.json`）。GUI ではホームの基礎打ちの行の「見どころの動画を作る」。
- 練習の動画 IMG_5287（4K・30fps・438 秒、打球 594 本）：打ち合い 24 本、上位 3 本（112・50・50 本。60・32・32 秒）を 1080p で 2 分 20 秒。

## 書き方

- フレームを 1 枚ずつ読んで描いて書くので、長い動画でもメモリは増えない。
- ffmpeg があれば H.264（`libx264`・`crf 20`）で書き、元の動画の音（AAC）も入れる。スロー動画（撮影の fps と再生の fps が違う）は
  音の長さが合わないので音を入れない。ffmpeg がなければ OpenCV（mp4v・音なし）で書く。
- 書き出す高さは、既定で 1080 と元の高さの小さい方（4K は 1080p に縮める）。`--height` で変えられる。
- 文字は Windows のメイリオ（なければ游ゴシック・MS ゴシック）で書く。日本語の字体がなければ英語にする。
- 速さの目安：IMG_5109（2530×1422・30fps）の 16 秒を 1080p で書くのに約 11 秒（動画の長さの約 0.7 倍）。
