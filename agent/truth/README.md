# コマを見て決めた正解

実動画の打球を、コマを見て 1 本ずつ決めたもの。動画・コマの画像はここに置かない（時刻と打った側だけ）。

- `IMG_5109_hits.csv`：練習の動画 IMG_5109（40 秒、Issue #10）。`t_s` 打った時刻（秒、±0.05 秒ほど）、`side` 打った側
  （`h` 手前・`o` 奥）、`rally` ラリーの番号（1：0〜19.5 s、2：21.55〜28.0 s、3：31.8 s〜）。動画の始まる前の打球（0 s の奥）は入れていない。

- `IMG_5109_1_hits.csv`（19 秒、2 ラリー）・`IMG_5109_2_hits.csv`（10 秒、1 ラリー）：同じ練習の動画の続き。列は同じ。
- `IMG_4397_80_100_hits.csv`：IMG_4397 の 80〜100 s（2 ラリー）。80 s より前に打った球は入れていない。

時刻は軌道の向きが変わる所・ラケットの振り・打球音から決めた（±0.05 秒ほど。サーブ・画面の上の外から落ちてくる球は ±0.1 秒ほど）。
ラリーの終わりに選手の近くへ落ちただけ・打つ前の構え・ラリーの間にシャトルを拾う所は入れていない。
`agent/checks/check_real_hits.py` がこの 4 つと比べる（区間とキャリブレーションは `agent/checks/real_hits_clips.json`）。

ショットの一覧の `shots.csv` と比べるときは、時刻の差 0.3 秒以内で近い順に 1 対 1 で組にする（D1c で使った数え方）。
